코스튬 대여 쇼핑몰 V3.5

[로컬 실행]
1. 이 폴더에서 CMD를 엽니다.
2. 최초 1회: py -m pip install -r requirements.txt
3. 실행: py app.py
4. 고객화면: http://127.0.0.1:5000
5. 관리자 로그인: http://127.0.0.1:5000/admin/login

[V3.5 추가 기능]
- 상품 등록 시 상세 설명과 이미지 여러 장 업로드
- 상품 수정 화면에서 상세 블록 추가, 교체, 삭제 및 순서 변경
- 고객화면에서 이미지·텍스트를 등록 순서대로 세로 표시
- 관리자 > 운영 설정에서 공통 대여안내 작성, 상품별 노출 선택

[V3.4.1 포함 기능]
- 밝은 화이트/보라/핑크 메인 디자인
- 시즌별 메인 배너 관리자 업로드 및 노출기간 예약
- PC/모바일 배너 이미지 분리
- 카테고리 추가/수정/삭제, 대표이미지, 메인노출, 순서관리
- 상품과 여러 카테고리 연결
- BEST/시즌추천 상품 지정 및 노출순서
- 관리자 > 메인관리에서 통합 관리

[Railway]
기존 GitHub 저장소에 V3.5 파일을 덮어쓴 뒤 Commit/Push하면 Railway가 자동 재배포합니다.
기존 /data Volume을 그대로 사용하면 주문/상품 데이터가 유지되며 init_db()가 V3.5 테이블을 자동 추가합니다.
